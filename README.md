KyraDock is a cool ai assistant, that plays role like a helping hand by performing tasks from voice control and automation to running apps and managing smart home devices.
im using a voice model to get most accurate voice recognition, and cloud based powerful and fast ai apis, with multi models feature. with a powerful control panel one on dock and other on phone to control surrounding.
