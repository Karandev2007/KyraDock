## KyraDock

KyraDock is a Powerful developer friendly AI Assistant device, that have super useful features like voice controls, automations, gesture controls, AI Vision, media server, control access panel and more.

## Example Tasks List:

* Set alarms, reminders, ask questions, get some work done using voice controls.
* Show Kyra some object, she will capture image and give info fetched from vision ai api in backend.
* Gesture controls, wave hand to right to change song to next, show victory sign to see a victory animation.
* Connect hard drives, pendives and more and use it as media server.
* Powerful control Panel + Phone app to control KyraDock.
* Full time Security Camera and activity logger (this will be really helpful)

I have more ideas with this like music visualizer on screen, custom animations of a custom avatar to represent to user for actions, gesture controls and more.
